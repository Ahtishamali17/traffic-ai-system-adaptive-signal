# API Documentation

Full interactive docs (Swagger UI) are auto-generated by FastAPI and served
at `/api/docs` (ReDoc at `/api/redoc`) whenever the backend is running —
that's the source of truth for exact request/response schemas. This page is
a quick reference for what exists and why.

Base URL: `http://localhost:8000/api/v1` (dev) or `https://your-domain/api/v1` (prod, behind Nginx)

## Detection

| Method | Path | Purpose |
|--------|------|---------|
| POST | `/detection/upload` | Upload a video file (mp4/avi/mov/mkv/webm, max 500MB) |
| POST | `/detection/start` | Start a detection session (webcam/RTSP/IP camera/uploaded file) |
| POST | `/detection/stop/{session_id}` | Stop a running session |
| GET | `/detection/sessions` | List all sessions (running + stopped) |
| GET | `/detection/sessions/{session_id}` | Status of one session |
| GET | `/detection/sessions/{session_id}/counts` | Live entry/exit/class counts (needs `counting_line` configured) |
| GET | `/detection/sessions/{session_id}/violations` | Last 50 violation events for this session |
| GET | `/detection/sessions/{session_id}/heatmap` | JPEG snapshot with density heatmap overlay |
| GET | `/detection/stream/{session_id}` | Live MJPEG annotated video stream |

`POST /detection/start` accepts optional nested config: `counting_line`
(two points), `violations` (wrong-direction angle, lane polygon, stop line,
no-parking zone), `pixels_per_meter` / `speed_limit_kmph` (speed
calibration), and `enable_alerts` (Telegram/email dispatch). See the
Swagger UI for the full schema — it's large enough that hand-copying it
here would drift out of sync.

## Analytics

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/analytics/summary?camera_id=&days=` | Hourly/daily counts, class breakdown, peak hour, violation totals |

## Reports

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/reports/csv?camera_id=&days=` | Daily vehicle counts as CSV |
| GET | `/reports/excel?camera_id=&days=` | Multi-sheet Excel workbook |
| GET | `/reports/pdf?camera_id=&days=` | Formatted PDF summary |

## Health

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/api/health` | Liveness/readiness probe (not under `/v1`) |

## Example: start a session with counting + violations + alerts

```bash
curl -X POST http://localhost:8000/api/v1/detection/start \
  -H "Content-Type: application/json" \
  -d '{
    "source_type": "webcam",
    "source": "0",
    "camera_id": "gate-1",
    "counting_line": {
      "point_a": {"x": 0, "y": 240},
      "point_b": {"x": 640, "y": 240}
    },
    "pixels_per_meter": 8.0,
    "speed_limit_kmph": 60,
    "violations": {
      "enable_violations": true,
      "correct_direction_deg": 0,
      "stop_line_a": {"x": 0, "y": 300},
      "stop_line_b": {"x": 640, "y": 300}
    },
    "enable_alerts": true,
    "crowd_threshold": 15
  }'
```
